# 儿童安全守护系统 (Kids Tracker)

> 高精度定位、实时防走失距离预警、自动拨号/短信/录音取证与三层安全鉴权系统。
> 版本: v3.0.0 (商业安全增强版)

---

## 模块架构

- **:child (孩子端 App)**: 运行在孩子设备上，提供前台/后台高精度 GPS 持续定位、10分钟动态配对码 (OTP)、防卸载保护以及越界自动拨号/短信/录音取证。
- **:parent (家长端 App)**: 运行在家长设备上，提供全屏高德地图沉浸式监控、5秒自动轮询刷新及防走失超限报警（手机震动 + 响铃 + 一键静音）。
- **:backend (后端服务)**: Spring Boot 3.3 + H2 JPA RESTful 服务端，负责设备配对、位置中转与安全鉴权。
- **:core (核心库)**: 共享 API 接口与 Retrofit 数据模型。

---

## 三层安全与隐私架构

1. **动态 10 分钟口令 (动态 OTP)**: 6位配对码 10 分钟自动过期刷新，防止静态配对码带来的隐私泄露。
2. **账号与 JWT 鉴权**: 家长端支持账号登录与 Token 凭证校验 (`Authorization: Bearer <Token>`)。
3. **多租户授权隔离**: 后端严格校验主守护人与设备的绑定关系，防止越权访问。

---

## 核心功能与亮点

### 1. 现代商业级界面
- **家长端**: 全屏地图、顶部在线状态与 5 秒自动轮询，底部卡片显示电量、最后上报时间与详细地址。
- **孩子端**: 守护绿主题、大字号动态配对码、倒计时器及权限配置引导。

### 2. 防走失安全防线与联动处置
- **安全半径**: 支持 50米、100米、200米、500米、1000米可选。
- **震动与响铃联动**: 超出安全范围时触发强力震动与响铃报警。
- **一键手动静音**: 报警触发后随时可手动关闭响铃与震动。
- **越界自动拨号/短信/录音**: 越界瞬间自动拨打家长电话、发送带精确地址的短信，并自动开启 30 秒环境录音取证。

### 3. 硬核后台守护
- **Android 14+ 前台服务**: 保持高精度 GPS 持续采集，即使锁屏或退至后台依然稳定运行。
- **防卸载保护**: 支持设备管理器与无障碍辅助插件，防止误删。

## 快速上手

1. **启动后端**:
   ```bash
   ./gradlew :backend:bootRun
   ```
   服务地址: `http://localhost:8080/` (模拟器: `http://10.0.2.2:8080/`)。
2. **编译部署 Android 应用**:
   - 安装 `:child` 到孩子设备并开启守护权限。
   - 安装 `:parent` 到家长设备，打开设置输入孩子端 6 位动态配对码完成绑定。
